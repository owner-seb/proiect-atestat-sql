Cum funcționează site-ul?

Site-ul este format doar din fișiere HTML, CSS și JavaScript. Interogările SQL rulează direct în browser, cu ajutorul bibliotecii sql.js (motorul SQLite compilat în WebAssembly), deci nu este nevoie de server.
